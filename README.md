## Overview
A classic PHP web application designed to manage equipment inventory, track item borrowing cycles, and record return confirmations with MySQL database integration.

---

## Key Features
- Complete CRUD operations for item inventory and borrower records
- Lending date and expected return date tracking
- Direct MySQL database connection via PHP mysqli/PDO

---

## Tech Stack
- **Language**: PHP
- **Database**: MySQL
- **Frontend**: HTML5, CSS3, Bootstrap

---

## Project Structure
```text
peminjaman-/
├── config.php          # Database configuration
├── index.php           # Item & loan overview
├── create.php          # Add new borrowing record
├── edit.php            # Update loan status
└── delete.php          # Remove record
```

## Getting Started

### Prerequisites
Make sure you have the required runtimes and tools installed on your machine:
- Node.js (v18+ recommended) / Appropriate runtime
- Git

### Installation & Local Setup
```bash
git clone https://github.com/MohammadKevin/peminjaman-.git
# Place directory in your local web server (e.g. htdocs for XAMPP)
# Import database schema into MySQL
# Update database credentials in config.php
# Access via http://localhost/peminjaman-
```
